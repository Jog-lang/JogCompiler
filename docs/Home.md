# Home

The Jog knowledge store lives in [JogDocs](https://github.com/Jog-lang/JogDocs). A local checkout is the sibling folder `../JogDocs`, or `../Jog/JogDocs` when the notes sit next to a `Jog` checkout. Start at its `AGENTS.md` and `guide/JogQuickRef.md`. The language notes there are the specification, and friction is logged in its `bootstrap/Friction.md`.

This folder keeps only the V1 compiler plans, because they describe how this repository is built and how its work is split:

- [[plans/V1Compiler]]: the V1 compiler architecture and milestones.
- [[plans/V1Parallel]]: the parallel work streams, file ownership, and contract headers.

JogDocs keeps stubs with the same names that point back here.
