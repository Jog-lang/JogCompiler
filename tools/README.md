`ct_util` is a static library of small C helpers: an arena allocator (`arena.h`), diagnostics (`diag.h`), a file reader (`file.h`), and a string-keyed hashmap (`map.h`). `da.h` is a realloc-backed dynamic array, and `coro.h` is a single-threaded GCC/Clang x86_64 coroutine scheduler for the host compiler (`coroutine_init`, `coroutine_go`, `coroutine_yield`, `coroutine_id`, `coroutine_alive`, `coroutine_shutdown`). The CTest target `util_test` covers them.
